SmartDesk AI
AI-Based IT Helpdesk Ticket Classification and Priority Prediction System

Project Type: Final Year Project (FYP)
Degree Program: BS Information Technology
Semester: 7th Semester

1. Introduction

IT helpdesk systems are used by organizations to manage technical complaints and support requests. Manually reviewing and assigning tickets can consume time and may result in delays in handling important issues.

SmartDesk AI is a proposed web-based system that uses machine learning to classify IT support tickets into relevant categories and predict their priority. The system will also provide an interface for managing tickets and viewing reports.

2. Problem Statement

Manual classification and prioritization of IT support tickets can be inefficient, particularly when many requests are received. A system that assists in categorizing tickets and estimating their priority could help support staff organize and manage requests more efficiently.

3. Objectives
Develop a web-based IT helpdesk ticket management system.
Use machine learning to classify ticket descriptions into predefined categories.
Predict ticket priority using available labeled data.
Provide an interface for users and administrators to manage tickets.
Store ticket records and display summary reports.
Evaluate the machine learning model using appropriate performance metrics.
4. Proposed Features
User ticket submission.
Automatic ticket category prediction.
Priority prediction, such as low, medium, or high.
Ticket status tracking.
Administrator dashboard.
Ticket search and filtering.
Basic reports and visualizations.
5. Proposed Methodology

The project will follow these stages:

Collect or prepare a suitable labeled dataset of IT support tickets.
Clean and preprocess ticket descriptions and labels.
Extract text features using TF-IDF.
Train and compare suitable machine learning classifiers.
Evaluate model performance using precision, recall, F1-score, and a confusion matrix.
Develop a web application and integrate the trained model.
Test the application and document the results.
6. Proposed Technologies
Programming Language: Python
Machine Learning: Scikit-learn
Data Processing: Pandas
Web Application: Streamlit
Database: SQLite
Visualization: Matplotlib
7. Expected Outcomes

The expected outcome is a working prototype that allows users to submit IT support tickets, predicts their categories and priorities, and provides administrators with ticket management and reporting features.

Actual classification performance will be measured using test data.

8. Scope and Limitations

The initial system will focus on text-based IT support tickets and predefined categories. Prediction quality will depend on the quality and representativeness of the training dataset. Automated predictions will assist administrators and will not replace human judgment.

9. Conclusion

SmartDesk AI aims to improve IT support ticket organization through machine learning and a simple web-based management interface. The project combines software development, database management, and applied artificial intelligence in a practical IT solution.
